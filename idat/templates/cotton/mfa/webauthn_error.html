{% comment %} MFA / WebAuthn Error Shows why the browser's security key or passkey prompt failed. allauth's webauthn.js catches the error and dispatches "allauth.error" on document. This listens and shows a message by the DOMException's name: InvalidStateError the key or passkey is already added (excludeCredentials) NotAllowedError the prompt was cancelled or timed out anything else a generic failure Use it once per page, on pages that run allauth's WebAuthn script, next to the form's server-side errors.
