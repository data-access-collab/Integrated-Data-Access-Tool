{% comment %} Platform tag carrying the status of that platform's access application (one project → many applications). Statuses follow the Art. 40(12) flow: Draft → In review (submitted / vetting) → Clarification requested → Granted / Rejected. Shape + colour, so it works without colour too. Only "Clarification requested" gets a tinted chip. Withdrawn = the researcher withdrew the application (neutral ✕, name struck through).
