Props: form Django form with the fields platform, response_type, response_date, reply, reply_file (FileField), deadline and remind (:form="reply_form") action form target (POST) id dialog id, default "log-platform-reply" open boolean attribute: render open in place (gallery) Open it with $dispatch('open-dialog', { id: 'log-platform-reply' }). Cancel and × close it without saving. The reply file is a plain upload submitted with the form (not the browser-encrypted wizard flow): .pdf, .eml or .msg, max. 10 MB, checked in the browser.
