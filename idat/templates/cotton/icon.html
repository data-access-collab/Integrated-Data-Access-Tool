{% comment %} Lucide icon. Shapes come from idat/templates/icons/.svg (a complete Lucide SVG; its root attributes are ignored, this component sets size, stroke and aria). Usage: 16px, status colour 18px, as in Wizard / Section Item 20px (default), inherits text colour meaningful icon → announced by screen readers - Colour comes from the text colour (currentColor). Dark mode works automatically. - Size via class (size-4 = 16px, size-4.5 = 18px, size-5 = 20px, size-6 = 24px). Passing class replaces the default, so always include a size. - The stroke stays 1.75px at every size. - Without label the icon is decorative (aria-hidden). Inside a button that has no visible text, put the label on the icon or use aria-label on the button. - Unknown name → TemplateDoesNotExist (loud on purpose, so typos don't fail silently). {% endcomment %}
