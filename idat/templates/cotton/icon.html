{% comment %} Lucide icon (stroked), or a platform logo (logo-: Simple Icons, filled). Only names in idat/assets/icons/allowlist.json exist; their shapes are built into idat/core/icons/icons.json by `npm run build:icons`. This component sets size, stroke and aria. Usage: 16px, status colour 18px, as in Wizard / Section Item 20px (default), inherits text colour meaningful icon → announced by screen readers - Colour comes from the text colour (currentColor). Dark mode works automatically. - Size via class (size-4 = 16px, size-4.5 = 18px, size-5 = 20px, size-6 = 24px). Passing class replaces the default, so always include a size. - The stroke stays 1.75px at every size (icon-stroke in input.css overrides Lucide's 2). - Without label the icon is decorative (aria-hidden). Inside a button that has no visible text, put the label on the icon or use aria-label on the button. - Unknown name → UnknownIconError (loud on purpose, so typos don't fail silently). {% endcomment %} {% get_icon name as icon %}
